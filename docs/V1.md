# Publication V1 de www.lemondeaime.com

## Décision proposée sur la persistance : V1 « bêta locale »

La sauvegarde durable liée au compte n'est pas prête : il n'y a encore ni tables, ni API, ni stockage d'images, ni quotas, ni droits pour les projets, les cubes et les bibliothèques. La construire correctement est un lot à part (V1.1), avec votre accord sur la base de production.

En V1 :

- **Sauvegardé sur le compte (serveur) :** compte et session ; nom ; timbre confirmé et première visite du Monde (après la migration) ; notes du Point Zéro d'une personne connectée (après la migration) ; espaces et membres.
- **Sur l'appareil, annoncé « Bêta » :** projets du Point Zéro et leurs images, mini-sites, cube, bibliothèque du Réseau, compositions du Canevas.
- **Mention visible :** au Point Zéro, sur la page projet et dans Mon espace. Le cube, le Réseau et le Canevas le disaient déjà.
- **Export :** « Sauvegarder tout dans un fichier » (Mon espace) emporte désormais aussi les projets et les images du Point Zéro (IndexedDB), sans perte. La restauration ajoute ce qui manque, remplace seulement sur demande et n'efface jamais.

## Tests

- `npm test` : suites node, sans base ni secret.
- `node scripts/serveur-test.cjs` puis, dans un autre terminal :
  - `node tests/navigateur/parcours.cjs` : ordinateur, téléphone et mouvement réduit ; photo → projet → Canevas → Réseau → ajout après sept vérifications ;
  - `node tests/navigateur/accessibilite.cjs` : WCAG 2.1 AA, onze pages, ordinateur et téléphone ; échoue sur toute anomalie critique ou sérieuse.
- Le workflow `.github/workflows/tests.yml` lance les trois à chaque PR. Pour qu'il **bloque** la fusion, une règle de branche est à activer dans GitHub (réglage du dépôt, à votre main).
