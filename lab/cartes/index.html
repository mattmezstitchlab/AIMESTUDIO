Trois cartes, à comparer.

AIME porte aujourd'hui trois modèles de carte, nés à trois endroits. Les voici côte à côte, avec ce que ce navigateur contient pour chacun. Rien n'est fusionné : on regarde, on compare, on décidera plus tard.

Les trois modèles

A · carte/

La Carte universelle

localStorage « aime-carte » · carte/carte.js

Qui la crée
La personne elle-même, rubrique par rubrique (nom, couleurs, moments, formations, voyages, compétences, rêves, contributions…).
Confidentialité
Privée par défaut ; visibilité réglée par rubrique ; date de naissance et relations jamais publiques ; publication avec consentement daté, révocable.
Ce qu'elle sait faire
Versions, export JSON et PNG, vue publique calculée, registre filtrable, mises en relation expliquées.
La voir sur le cube
B · Studio, uni*

Les Cartes universelles du Studio

« aime:uni », « aime:cards », « aime:unilinks » · studio/index.html

Qui la crée
Le Studio, à partir des personnes présentes dans les projets (invités, équipe) ; chacune reçoit un code « AIME-… ».
Confidentialité
En attente tant qu'elle n'est pas réclamée ; niveaux privé, événement, public ; un mineur reste toujours privé.
Ce qu'elle sait faire
Agréger les événements, les supports et l'activité (badgeuse) d'une personne ; profil public par code ; registre et fil d'activité.
Ouvrir le Studio
C · Le Monde AIME

« Votre carte » de la landing

localStorage « aime-mem » · aime/index.html

Qui la crée
Le parcours de la landing : « Qui êtes-vous ? » (Moi, Pro, Participant, Coordinateur), le projet, le nom, les épingles et la frise.
Confidentialité
Tout reste dans le navigateur ; pas de publication.
Ce qu'elle sait faire
Habiller le cube et s'ouvrir sur l'essentiel : profil, agenda, budget, messages, documents, médias.
