Comment ça marche

Une saisie, et chaque atelier fait sa part

Les ateliers lisent le même projet. Ce que vous écrivez dans l'un sert aux autres, sans copier-coller.

01

Vous ouvrez un atelier

Stitchlab pour un patron, la Timeline pour un mariage, Studio Docs pour un devis.

02

Le projet se range tout seul

Il apparaît dans Dossiers. Vous le classez dans vos propres dossiers d'un glisser-déposer.

03

Le Bureau propose la suite

Après un patron : le facturer, le vendre sur un site, en faire un visuel. Un clic ouvre l'atelier sur le même projet.

04

Vos données restent chez vous

Tout est gardé dans votre navigateur. Rien n'est envoyé sans que vous le décidiez.
